# Ebaniscana

Sitio web informativo creado con React, Vite y desplegado en Vercel.

## Desarrollo

```sh
npm install
npm run dev
```

## Formulario de contacto

El formulario envía las consultas a EmailJS desde el navegador. Configura en el panel de EmailJS el servicio de correo, la plantilla, el destinatario y los dominios permitidos. La integración envía los campos `nombre`, `email`, `telefono`, `ciudad` y `mensaje`.

## Despliegue

Vercel reescribe las rutas de la aplicación a `index.html`. El dominio publicado actualmente usa HTTPS. `public/sitemap.xml`, `public/robots.txt` y `public/404.html` contienen recursos auxiliares del sitio.
